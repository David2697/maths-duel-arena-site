Privacy policy

Maths Duel Arena collects no personal data. The game keeps everything on this device and sends nothing to us. Purchases are made through Google Play, which handles the payment.

What the game keeps, on this device only

  • Progress: games played, answers, stars, ranks, gems, hearts, achievements, titles, looks and statistics.
  • Settings: sound, language, animations, timer, reminders, and the play mode chosen on the first start, Relaxed or Challenge (it only chooses the default settings).
  • Players on this device: the name or nickname typed for each player, and their progress.
  • Challenges and ghosts: the codes typed or received, the names a teacher types next to result codes, and the names typed next to a friend's ghost.
  • Purchases: what was bought (gem packs, passes, plans) and the confirmation Google Play sends, so that the game can give what was paid for.

Purchases

  • Gem packs and passes (Arena Pass, Journey Pass, Family plan) are bought with real money through Google Play. Google Play handles the payment and the Google account; the game never sees a name, an address or payment details.
  • Before any purchase, a question meant for a parent is asked. Children should ask a parent before buying.
  • Subscriptions renew until cancelled, and are cancelled in the Google Play app (Payments & subscriptions).
  • Everything needed to learn stays free: lessons, Practice, every notion and every level.

What the game does not do

  • No account, no sign-in, no e-mail address.
  • No advertising.
  • No connection to our servers: the game itself does not use the internet, except when you choose to send us a message (see "Contact us" below). Purchases go through the Google Play app. Nothing else is shared with us or with anyone else.
  • The app asks Android for internet access, kept for optional ads planned in a later version (see below). In this version the game sends nothing over it.
  • No location, contacts, camera, microphone or photos.
  • No analytics and no crash reports.
  • No chat and no messages between players.

Codes

None of these codes holds a name. Players share them themselves, by hand.

  • A challenge code holds only the questions' settings (notions, levels, number of questions, timer).
  • A 1 vs 1 result code holds, for each round, the number of right answers and the time.
  • A class result code holds, for each question, whether the answer was right, which answer was chosen (or that time ran out), and the total time. A teacher sees them only when the pupil gives the code.
  • A ghost code holds the questions' settings and, for each question, whether it was right and how long it took.
  • A "refer a friend" code is a random code.

Contact us

Settings → Contact us sends us a message only when you press Send. It contains the title and message you typed, a screenshot if you chose one, the e-mail address you typed if you want an answer (optional; a parent's address for children), and the game's version and language. It travels over an encrypted connection through Google's service (Google Apps Script) and reaches us as an e-mail. We use it only to answer and to improve the game, never for advertising, and we delete it when it is no longer needed (at the latest one year later). Nothing is sent if you don't press Send.

Reminders

Reminders are off until a parent turns them on in Settings, behind the parent question. They are scheduled on the device; nothing is sent over the internet. The parent summary can be turned off in Settings.

Backup

If the phone's owner has turned on Android's own backup, Android may copy the game's progress and players to that Google account, so that they move to a new phone. This is Android's backup, not ours: we never receive it.

Erasing the data

  • Settings → Reset my progress erases this player's progress.
  • A player can be removed from the players list.
  • Uninstalling the app erases everything on the device.

Children

The game is made for children. It is designed so that no personal data leaves the device. Purchases and the settings that matter (reminders, erasing progress) are behind a question meant for a parent.

Changes

If a future version changes anything here (for example to add online play or advertising), this policy will be updated before that version is released, and the change will be described in it.

Ads planned for a later version: only a video a player chooses to watch (for a heart in a boss), after a parent's answer, from an ad network certified for children's apps, with no personalised ads. The data that network receives will be listed here before that version is released.

Contact

Questions about this policy: write to the e-mail address shown on the game's store page.

Politique de confidentialité

Maths Duel Arena ne collecte aucune donnée personnelle. Le jeu garde tout sur cet appareil et ne nous envoie rien. Les achats se font par Google Play, qui s'occupe du paiement.

Ce que le jeu garde, sur cet appareil uniquement

  • La progression : parties jouées, réponses, étoiles, rangs, gemmes, cœurs, succès, titres, apparences et statistiques.
  • Les réglages : son, langue, animations, chrono, rappels, et le mode de jeu choisi au premier lancement, Détente ou Défi (il ne sert qu'à choisir les réglages de départ).
  • Les joueurs de cet appareil : le prénom ou pseudo tapé pour chaque joueur, et sa progression.
  • Les défis et les fantômes : les codes tapés ou reçus, les noms qu'un professeur tape à côté des codes de résultat, et les noms tapés à côté du fantôme d'un ami.
  • Les achats : ce qui a été acheté (packs de gemmes, pass, offres) et la confirmation envoyée par Google Play, pour que le jeu donne ce qui a été payé.

Achats

  • Les packs de gemmes et les pass (Pass Arène, Pass Parcours, Offre Famille) s'achètent avec de l'argent réel par Google Play. Google Play s'occupe du paiement et du compte Google ; le jeu ne voit jamais de nom, d'adresse ni de moyen de paiement.
  • Avant tout achat, une question destinée à un parent est posée. Les enfants doivent demander à un parent avant d'acheter.
  • Les abonnements se renouvellent jusqu'à leur résiliation, qui se fait dans l'application Google Play (Paiements et abonnements).
  • Tout ce qui sert à apprendre reste gratuit : leçons, Entraînement, toutes les notions et tous les niveaux.

Ce que le jeu ne fait pas

  • Pas de compte, pas de connexion, pas d'adresse e-mail.
  • Pas de publicité.
  • Pas de connexion à nos serveurs : le jeu lui-même n'utilise pas internet, sauf si tu choisis de nous envoyer un message (voir « Nous contacter » plus bas). Les achats passent par l'application Google Play. Rien d'autre n'est partagé avec nous ni avec personne.
  • L'application demande à Android l'accès à internet, gardé pour des publicités facultatives prévues dans une prochaine version (voir plus bas). Dans cette version, le jeu n'envoie rien.
  • Pas de localisation, de contacts, de caméra, de micro ni de photos.
  • Pas de statistiques d'utilisation ni de rapports de plantage.
  • Pas de discussion ni de messages entre joueurs.

Codes

Aucun de ces codes ne contient de nom. Les joueurs se les échangent eux-mêmes, à la main.

  • Un code de défi ne contient que les réglages des questions (notions, niveaux, nombre de questions, chrono).
  • Un code de résultat de 1 contre 1 contient, pour chaque manche, le nombre de bonnes réponses et le temps.
  • Un code de résultat de classe contient, pour chaque question, si la réponse était juste, quelle réponse a été choisie (ou que le temps est écoulé), et le temps total. Un professeur ne le voit que si l'élève lui donne le code.
  • Un code de fantôme contient les réglages des questions et, pour chaque question, si elle était juste et le temps mis.
  • Un code « parrainer un ami » est un code tiré au hasard.

Nous contacter

Réglages → Nous contacter ne nous envoie un message que lorsque tu appuies sur Envoyer. Il contient le titre et le message que tu as écrits, une capture d'écran si tu en as choisi une, l'adresse e-mail que tu as tapée si tu veux une réponse (facultatif ; celle d'un parent pour les enfants), ainsi que la version et la langue du jeu. Il passe par une connexion chiffrée via le service de Google (Google Apps Script) et nous arrive sous forme d'e-mail. Nous l'utilisons uniquement pour répondre et améliorer le jeu, jamais pour de la publicité, et nous le supprimons quand il n'est plus utile (au plus tard un an après). Rien n'est envoyé si tu n'appuies pas sur Envoyer.

Rappels

Les rappels sont désactivés tant qu'un parent ne les active pas dans les Réglages, derrière la question pour les parents. Ils sont programmés sur l'appareil ; rien ne passe par internet. Le résumé pour les parents peut être désactivé dans les Réglages.

Sauvegarde

Si le propriétaire du téléphone a activé la sauvegarde d'Android, Android peut copier la progression et les joueurs du jeu sur ce compte Google, pour les retrouver sur un nouveau téléphone. C'est la sauvegarde d'Android, pas la nôtre : nous ne la recevons jamais.

Effacer les données

  • Réglages → Réinitialiser ma progression efface la progression de ce joueur.
  • Un joueur peut être retiré de la liste des joueurs.
  • Désinstaller l'application efface tout sur l'appareil.

Enfants

Le jeu est fait pour les enfants. Il est conçu pour qu'aucune donnée personnelle ne quitte l'appareil. Les achats et les réglages importants (rappels, effacement de la progression) sont protégés par une question destinée à un parent.

Modifications

Si une prochaine version change quoi que ce soit ici (par exemple pour ajouter le jeu en ligne ou de la publicité), cette politique sera mise à jour avant la sortie de cette version, et le changement y sera décrit.

Publicités prévues dans une prochaine version : seulement une vidéo qu'un joueur choisit de regarder (pour un cœur pendant un boss), après la réponse d'un parent, venant d'une régie certifiée pour les applications destinées aux enfants, sans publicité personnalisée. Les données reçues par cette régie seront listées ici avant la sortie de cette version.

Contact

Pour toute question sur cette politique : écrivez à l'adresse e-mail indiquée sur la page du jeu dans le store.
